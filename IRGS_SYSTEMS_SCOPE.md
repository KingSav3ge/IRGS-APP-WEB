# Shared IRGS systems — current development scope

User correction, 25 October 2026: develop IRGS across campaigns and themes.
Target: IRGS 3.4.0 development. Solo describes the hosting/player mode.
Rise R00 is one regression fixture within the shared system.

## Ownership and architecture

Engine owns Core rules, authorization, conserved effects, processes, received
information, receipts, recovery and its offline response runtime. App owns the
common host, player/Creator interface, protected configuration and presentation.
Catalog owns the campaign-independent response depot, schemas, provenance,
campaign data and evaluation material. Keep each component independently owned.
Campaign/genre adapters supply selected rules, actual capabilities and known
labels. A campaign name, theme or authored phrase grants no execution authority.

Shared priorities include intent/proposal/acceptance, movement and perception,
resources/capacity, time and durable processes, communication and obligations,
continuing-world authority and institutions. Preserve stable DEV/C2 requirements
and qualify each supported increment. Existing holds and unsupported rules stay
explicit; this scope correction adopts no new simulation rules or playable starts.

## Routine responses without inference

Use the Catalog depot across campaigns: 750 stored system variants and 250
editable drafts, with recipes counted separately. Keep historical packs under
their original identities. Generic semantic intent tags remain separate from
campaign operation IDs. Engine/App provide their own requested runtime layers
and explicit compatible adapters; avoid divergent copies of campaign truth.

Build text from actor-legitimate views, received records and actual committed
receipts. Preserve exact outcomes, negation, uncertainty, sources and elapsed
spans. Draft selection changes no world state and requires explicit submission.
Routine rendering works with zero API calls and without credentials. Missing
templates/facts/rules retain a literal receipt or honest unresolved response.
AI remains an optional, separately approved capability for demanding supported
tasks. Never send the depot in full as a prompt or dispatch because text is absent.
