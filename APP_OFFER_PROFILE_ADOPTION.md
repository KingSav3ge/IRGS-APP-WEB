# Explicit optional Rise offer setup

This App increment adopts the pinned Engine's optional
`founder-household-offer-v1` setup choice. The normal Rise setup defaults to
**No stock offers**, omits the optional field in that case, and retains the
selection when returning from review or reopening cancelled setup. The normal
Engine review supplies the scope, no-consent/no-transfer notice, permitted
account, authority reference and source shown before explicit creation. The
Engine's review digest and the App's original creation identity remain in use.

This is a selected fictional profile for newly created campaigns. Existing
campaigns are not reseeded. No account, stock, NPC control, response or consent
is inferred by the App. The existing actor-scoped communication API remains the
execution path; a reviewed offer can record `offered` without reserving or
transferring stock. The exact own-response and communication drafts remain
independent. The chronological Story surface and received source statuses remain.

The new browser journey creates an ordinary non-Rise fictional quay opening and
a Rise campaign from an empty temporary store. It exercises back/cancel and
default omission, source-bound review, lost creation acknowledgement and same-ID
recovery, selected Core actions, exact offer words, cancel/reload/recover/confirm,
the actual `offered` receipt, retained independent drafts, unchanged founder
stock, and mobile Story layout. Provider endpoints are blocked; no live provider
or user save is used.

The active checkout is `/workspace/WORLDWARD-APP-WEB`. It was populated through
the authorized GitHub plugin because the CLI credential is invalid. Existing
Git objects were reused locally; every imported commit, tree and blob was
verified against its remote object SHA, and Git connectivity checks passed. The
older `/workspace/IRGS-APP-WEB` checkout and its pending edits were preserved.

The App remains 3.4.6 Pre-Alpha. The coordinator owns the next qualified joined
edition, 3.4.7. Engine and Catalog pins are unchanged by this increment.
Newer supported-intent communication DTO adoption, grant prerequisites, and
world-draft preview/editor remain next App work. General freeform interpretation,
NPC/institution decisions, arbitrary authoring and wider Alpha gates remain open.
Windows protected setup stays unavailable pending native ACL implementation and
qualification. Live-provider quality requires a separately authorized eligible
route and finite budget.
